# Documentation

These documents describe BrokenCode's Track 3 submission in both plain language
and implementation detail. The root [README](../README.md) remains the quick
start and the first place to look for current practice results.

## Choose a starting point

- **New teammate or demo reviewer:** read [Project overview](PROJECT_OVERVIEW.md).
- **Checking the hackathon brief:** read [Track 3 requirements](TRACK_3_REQUIREMENTS.md).
- **Maintaining or extending the implementation:** read [Codebase explained](CODEBASE_EXPLAINED.md).
- **Handling secrets, source data or releases:** read the [Security checklist](SECURITY.md).

The local `Secret-Wards-ToolKit` clone is ignored by Git and is not included in
this documentation set. The challenge statement and toolkit remain the
authoritative sources for the organizer's contract and scoring details.
